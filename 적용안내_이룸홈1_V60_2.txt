이룸홈1 V60.2 · 프리미엄/제철 상품 추가 + 통합 노출관리

핵심 추가 기능
- 상품관리 화면에 “프리미엄 · 제철 과일 빠른 노출 관리” 추가
- 봄/여름/가을/겨울을 선택하고 등록 상품을 프리미엄 또는 제철에 즉시 추가
- 프리미엄/제철 목록에서 순서 위/아래 이동, 삭제 가능
- 상품 등록/수정 창에 “홈페이지 노출 설정” 매트릭스 추가
- 상품 1개를 등록한 뒤 계절별로 메인/오늘 PICK/프리미엄/제철/과일 더보기 복수 노출 가능
- 같은 상품을 여러 영역에 노출해도 가격/재고/주문은 동일한 상품 DB 사용
- 상품명 변경 시 기존 홈페이지 노출 위치의 상품명도 함께 갱신
- 상품 삭제 시 홈페이지 노출 영역에서도 함께 제거
- 상품 상태를 ‘숨김’으로 저장하면 홈페이지 노출도 자동 해제
- 메인 과일은 기존 디자인 보호를 위해 계절별 최대 5개 제한 유지
- 프리미엄/제철은 추가 개수 제한 없이 구성 가능하며 기존 가로 스크롤/더보기 구조 유지
- 홈페이지 설정 저장 후 공개 설정 revision 재확인 방식 유지

추천 운영 흐름
1. 관리자 > 상품관리 > 상품 등록
2. 가격/재고/판매단위/이미지 입력
3. 같은 창 아래 ‘홈페이지 노출 설정’에서 원하는 계절/영역 체크
4. ‘상품 + 홈페이지 노출 저장’ 클릭
5. 필요하면 상품관리 상단 ‘프리미엄 · 제철 과일 빠른 노출 관리’에서 순서 조정
6. 홈페이지 전체 화면 편집에서 카드/상세 이미지와 문구를 최종 보정
