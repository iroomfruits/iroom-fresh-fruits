이룸 fresh fruits V28 ONE-CLICK RUN

가장 쉬운 실행 방법
1. ZIP 파일을 '모두 압축 풀기'로 완전히 풉니다.
2. 압축을 푼 폴더 안의 '실행하기.bat'를 더블클릭합니다.
3. 처음 한 번은 인터넷이 연결되어 있어야 합니다.
   PC에 Node.js가 없으면 공식 nodejs.org에서 무설치 node.exe를 자동으로 받아 runtime 폴더에 저장합니다.
4. 서버가 준비되면 브라우저가 자동으로 열립니다.

중요
- public/index.html을 직접 더블클릭하지 마세요.
  회원/관리자/사진업로드 기능은 서버로 실행해야 정상 작동합니다.
- 예전 START 파일은 사용하지 마세요.
- 이 버전은 3000번 포트가 사용 중이면 3001/3002/3010 등 사용 가능한 포트를 자동으로 찾습니다.
- Windows에 Node.js를 별도로 설치할 필요가 없습니다.
- 첫 실행 후 runtime/node.exe가 생기면 다음부터는 인터넷 없이도 기본 홈페이지 실행이 가능합니다.
  (외부 이미지/API/주소검색 등 인터넷 기능은 별도 인터넷 연결 필요)

실행 파일
- 실행하기.bat : 권장
- START_IROOM.bat : 같은 실행기
- 서버종료.bat : 실행 중인 이룸 서버 종료
- 실행진단.bat : 실행 문제가 생겼을 때 진단파일 생성

오류가 날 경우
logs/launcher.log
logs/server-error.log
logs/diagnostics.txt
를 확인하면 원인을 알 수 있습니다.
