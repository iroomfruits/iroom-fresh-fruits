IROOM HOME1 V60.5 - PWA 설치 카드 표시 수정

원인
- V60.4는 display-mode: standalone(설치된 앱으로 실행 중)인 경우 큰 설치 카드를 숨기고
  푸터의 작은 설치 문구만 '이룸 앱 설치됨'으로 바꾸도록 되어 있었습니다.
- 따라서 사용자는 앱 설치 영역이 사라진 것처럼 보일 수 있었습니다.

V60.5 변경
1. 설치된 앱으로 실행 중이어도 큰 앱 카드가 사라지지 않습니다.
   - '이룸 앱 설치됨' 버튼/상태로 설치 완료 여부를 명확히 표시합니다.
2. 일반 브라우저에서는 큰 '이룸 앱 설치하기' 카드가 항상 표시됩니다.
3. Chrome / Edge / Android: beforeinstallprompt가 제공되면 기본 설치창 실행.
4. iPhone / iPad: Safari 공유 -> 홈 화면에 추가 안내 제공.
5. 설치 프롬프트가 제공되지 않는 브라우저에서도 버튼을 누르면 수동 설치 안내를 표시합니다.
6. 업로드한 이룸 로고 아이콘을 64/180/192/512/maskable 512에 그대로 사용합니다.
7. 서비스워커 캐시를 V60.5로 갱신하여 이전 V60.4 캐시가 남는 문제를 줄였습니다.

배포 후 확인
- GitHub 패치 파일의 내용물을 저장소 루트에 덮어쓰기
- Render 배포 완료 후 Ctrl+F5
- 설치된 PWA는 완전히 종료 후 다시 실행
- 그래도 이전 화면이면 기존 PWA 삭제 후 웹사이트에서 다시 설치
