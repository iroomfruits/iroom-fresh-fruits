이룸 fresh fruits V22

추가 기능

1. AI 상품 이미지 고급화
ADMIN → 상품관리 → 상품수정 → AI 이미지 스튜디오
현재 대표이미지를 참고해 고급 전자상거래용 이미지로 리디자인합니다.
OpenAI API Key와 이미지 생성 사용 권한이 필요합니다.

2. AI 상세설명
상품수정 → AI 상세설명 만들기
맛/식감, 산지, 추천 대상, 보관방법, 선물용도를 포함한 상세설명을 작성해 설명란에 넣습니다.
관리자가 확인 후 저장합니다.

3. 구매자 아이디 확인 배송조회
고객 화면 상단 → 배송조회
로그인한 회원의 아이디 + 주문번호를 확인하고 해당 회원 소유 주문일 때만 배송정보를 표시합니다.
표시: 주문상태, 결제상태, 택배사, 송장번호, 배송 단계, 택배 배송조회 링크

관리자 초기 비밀번호: pa292513
