이룸 fresh fruits V36 - 네이버 BAND 실제 연동

추가 기능
- 관리자센터 > BAND 운영센터
- BAND Access Token 저장
- 가입한 BAND 목록 조회
- 게시할 BAND 선택 / band_key 저장
- 글쓰기 권한 자동 확인
- 상품 판매 게시글 자동 작성
- 네이버 BAND에 실제 게시글 전송
- 고객용 BAND 주소 https://band.us/@iroomfresh 연결

최초 연결 방법
1. https://developers.band.us 에서 My Apps로 이동
2. 서비스를 등록하고 BAND 계정을 연결하여 Access Token을 발급
3. 이룸 관리자센터 > BAND 운영센터 열기
4. Access Token 입력 후 '연결 정보 저장 / 새로 확인'
5. 목록에서 '이룸 fresh fruits' BAND 선택 후 다시 저장
6. 상품 선택 > 게시글 자동 작성 > 내용 확인 > 'BAND에 실제 게시하기'

중요
- 실제 게시에는 BAND 계정의 해당 밴드 글쓰기 권한이 필요합니다.
- Access Token은 외부에 공개하지 마세요.
- 게시 전 상품 가격, 재고, 배송 조건을 확인하세요.
- BAND 자체 개설은 BAND 앱/웹에서 먼저 완료되어 있어야 합니다. API는 기존 BAND 연동 및 게시에 사용합니다.
