- 상품 이미지
- 선물세트 이미지
- 배너·이벤트 이미지
- 상품 동영상
- 임시 보관

폴더에서 가능한 작업:
- 사진/동영상 업로드
- 새 폴더 만들기
- 이름 변경
- 폴더 이동
- 삭제
- 상품 대표사진으로 재사용

[사진 업로드]
기존 상품:
상품수정 → 파일선택 → '업로드 · 대표사진 적용 · 보관'

신규 상품:
상품정보 입력 + 사진 선택 →
'상품 등록 + 선택사진 적용'
상품 생성 → 대표사진 적용 → 이미지 보관 폴더 저장
