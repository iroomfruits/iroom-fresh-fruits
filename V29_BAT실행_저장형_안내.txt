이룸 fresh fruits V29 - BAT 실행 / 저장형

실행 방법
1. ZIP 파일을 완전히 압축 해제합니다.
2. START_IROOM_V29.bat 또는 실행하기.bat 를 더블클릭합니다.
3. 검은 서버 창이 열리고 브라우저가 자동으로 열립니다.

필수
- Windows PC에 Node.js LTS가 설치되어 있어야 합니다.
- Node.js 설치 후에는 Windows를 한 번 다시 시작하는 것을 권장합니다.

홈페이지 주소
http://127.0.0.1:3000
3000번 포트가 사용 중이면 3001 또는 3002로 자동 변경됩니다.

저장 위치
- 상품/회원/주문/쿠폰/관리자 설정:
  data/store.json

- 업로드한 상품사진/동영상:
  public/uploads/library/

- 시작할 때 최근 데이터 백업:
  backup/store_latest_backup.json

즉, 관리자에서 수정 후 저장하면 BAT를 종료하고 다시 실행해도 그대로 남습니다.

주의
public/index.html을 직접 더블클릭하지 마세요.
관리자, 상품 업로드, 이미지 보관함, 주문, 저장 기능은 BAT 서버로 실행해야 정상 작동합니다.
