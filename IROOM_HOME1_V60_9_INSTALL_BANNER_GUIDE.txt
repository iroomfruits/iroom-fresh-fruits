이룸홈1 V60.9 설치 배너/아이콘 적용

1. 홈페이지 앱 설치 영역을 생성된 2번 가로형 배너 디자인으로 교체했습니다.
   - 배너 전체를 클릭하면 앱 설치 동작을 실행합니다.
   - 화면에는 추가 설명/상태문구를 노출하지 않아 깔끔하게 유지합니다.
2. 설치 앱 아이콘은 사용자가 지정한 1번 이룸 fresh fruits 로고를 여백을 줄여 크게 보이도록 재제작했습니다.
   - 32 / 64 / 180 / 192 / 512 / maskable 512
   - favicon.ico 포함
3. 설치 후 PWA로 실행 중일 때는 설치 배너를 숨깁니다.
4. Chrome/Edge/Android는 브라우저가 beforeinstallprompt를 제공할 때 시스템 설치창을 사용합니다.
5. iPhone/iPad는 Safari 정책상 공유 → 홈 화면에 추가 방식이 필요합니다.

배포 후 기존 앱/바로가기 아이콘이 남아 있다면 기존 항목을 삭제하고 다시 설치해야 새 아이콘이 확실히 표시됩니다.
