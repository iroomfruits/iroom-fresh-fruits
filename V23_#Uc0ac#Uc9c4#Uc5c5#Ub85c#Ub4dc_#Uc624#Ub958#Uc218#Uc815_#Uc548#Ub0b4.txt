이번 버전의 핵심 수정
- 사진 선택 즉시 미리보기

- 업로드 성공 즉시 상품 대표사진 서버 저장
- 별도 상품 저장 버튼을 다시 누르지 않아도 대표사진 반영
- 고객 홈페이지 상품사진 즉시 갱신
- 캐시 방지용 새 이미지 URL 처리
- 기존사진 삭제
- 동영상도 같은 방식으로 즉시 등록/삭제
- 모바일 파일 선택 지원
- 드래그 앤 드롭 지원(PC)
- 이미지 최대 12MB, 동영상 최대 80MB 안내/검사
- AI 이미지와 일반 사진 업로드 완전 분리
- OpenAI 크레딧이 없어도 일반 사진 등록/변경 정상 사용

사용 순서
1. ADMIN 로그인
2. 상품관리
3. 상품 수정
4. 대표 이미지에서 사진 선택
5. 미리보기 확인
6. '사진 업로드 · 바로 적용'
7. '대표사진 변경 완료 ✓'가 나오면 고객 화면에도 반영 완료
