IROOM HOME1 V60.29 HOME2 PRIVATE MARKET 적용방법

1. 현재 V60.28이 적용된 GitHub 저장소를 기준으로 합니다.
2. IROOM_HOME1_V60_29_HOME2_PRIVATE_MARKET_GITHUB_PATCH.zip을 압축 해제합니다.
3. 압축 안의 package.json / public/ 폴더 / 문서 파일을 GitHub 저장소 루트에 그대로 덮어씁니다.
4. 기존 저장소 파일 전체를 삭제하지 마세요. 같은 이름 파일은 교체하고 새 파일은 추가합니다.
5. Render 재배포가 끝나면 `/home2`를 확인합니다.
6. 예전 Home2가 보이면 브라우저 강력 새로고침 또는 사이트 캐시 새로고침을 한 번 해주세요.

확인 순서
- 메인 화보 사진이 과도하게 잘리지 않는지
- 빠른 과일 선택 버튼이 정상 동작하는지
- 오늘 이룸이 고른 과일 6종의 상세/구매/담기가 작동하는지
- 추가 마켓 5종의 구매가 작동하는지
- 선물 살롱 상담 버튼이 선물 상담창을 여는지
- 카카오 상담 버튼이 정상적으로 카카오 오픈채팅을 여는지
- 비회원 주문조회가 정상적으로 열리는지
- 모바일에서 햄버거 메뉴/상품 1열/가로 스와이프가 자연스러운지

이번 패치는 홈페이지2를 새로 구성하지만 홈페이지1, DB/API, 주문/회원/관리자는 변경하지 않습니다.
