이룸 fresh fruits V35 ONLINE - 실운영 준비판

이 버전은 V35 고객화면/관리자화면 스타일을 유지하면서 인터넷 실운영에 필요한 서버 기능을 보강했습니다.

[온라인 운영에 추가된 기능]
- 0.0.0.0 서버 바인딩
- HTTPS 리버스프록시용 설정
- Docker / Docker Compose
- Caddy 자동 HTTPS 예제
- Nginx 리버스프록시 예제
- 환경변수(.env) 비밀키 관리
- 관리자 로그인 횟수 제한
- 회원 로그인/회원가입/주문/상담 요청 속도 제한
- 관리자/회원 세션 만료
- data/store.json 원자적 저장
- 자동 백업 (최대 최근 30개)
- /api/health 서버 상태 확인
- /robots.txt 자동 생성
- /sitemap.xml 자동 생성
- 상품 고유주소 /product/상품ID
- 상품별 SEO 제목/설명/OG 이미지
- 네이버 서치어드바이저 meta 소유확인
- Google Search Console meta 소유확인
- 주문 발생 시 SMTP 이메일 알림
- Naver Cloud SENS 문자 알림
- 보안 헤더

[중요: 실제 결제]
PG Client Key/Secret을 입력하는 것만으로 카드결제가 자동 승인되지는 않습니다.
토스페이먼츠/KG이니시스/KCP/네이버페이 중 실제 계약한 PG사의 상점 ID 및 실운영 API 사양에 맞춘 최종 결제승인 연동이 필요합니다.
현재 온라인판은 결제수단 UI/주문/결제상태 관리 구조를 유지하며, PG 승인 전에는 실제 카드결제를 성공한 것으로 처리하면 안 됩니다.

[1. 가장 먼저]
.env.example 을 복사해 .env 생성

반드시 수정:
PUBLIC_URL=https://실제도메인
ADMIN_PASSWORD=충분히긴새비밀번호

선택:
OPENAI_API_KEY
SMTP_USER / SMTP_PASSWORD / ORDER_EMAIL
SENS_ACCESS_KEY / SENS_SECRET_KEY / SENS_SERVICE_ID / SENS_FROM / ADMIN_PHONE

[2. 서버]
Ubuntu VPS 또는 Docker가 가능한 국내/해외 서버 권장.
프로젝트 폴더 전체를 서버에 업로드한 후:

chmod +x deploy_ubuntu.sh
./deploy_ubuntu.sh

[3. 도메인]
도메인의 A 레코드를 서버 공인 IP로 연결합니다.
www도 사용할 경우 www 레코드도 연결합니다.

[4. HTTPS]
가장 쉬운 방법은 Caddy입니다.
Caddyfile.example의 example.com을 실제 도메인으로 변경하면 Let's Encrypt HTTPS 인증서를 자동 발급/갱신할 수 있습니다.

[5. 관리자]
관리자 → 사이트·결제·알림 설정
실제 홈페이지 주소(HTTPS) 입력
네이버/Google 소유확인 코드 입력
저장

[6. 네이버 검색]
배포 후 아래 주소가 열리는지 확인:
https://도메인/robots.txt
https://도메인/sitemap.xml
https://도메인/api/health

네이버 서치어드바이저에 도메인 등록 → 소유확인 → sitemap.xml 제출

[7. 데이터]
상품/회원/주문/설정:
data/store.json

상품 이미지:
public/uploads/library/

자동 백업:
backups/

Docker에서도 위 폴더는 볼륨으로 유지됩니다.

[8. 로컬 테스트]
Windows에서는 온라인판_로컬테스트.bat 로 먼저 확인할 수 있습니다.

[9. 사업자정보]
V35 관리자 설정에서 사업자등록번호를 입력하면 기존처럼 메인 하단 사업자정보에 표시됩니다.

[실운영 전 체크]
- 관리자 비밀번호 변경
- 개인정보처리방침/이용약관/환불정책 실제 사업 내용으로 검토
- 사업자등록정보와 통신판매업 신고정보 확인
- 실제 도메인/HTTPS
- 메일/문자 테스트
- PG사 계약 및 실결제 검수
- 배송/환불 업무 프로세스 확인
- 매일 자동 백업 외 외부 백업도 추가 권장

관리자 초기 개발용 비밀번호가 store.json에 남아 있더라도,
온라인 서버에서는 .env의 ADMIN_PASSWORD가 우선 적용됩니다.
