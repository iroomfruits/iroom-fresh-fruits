이룸 fresh fruits V24

추가 기능
- 상품 이미지 업로드 후 바로 대표사진 적용
- 상품수정 화면에서 기존사진 삭제 / 새사진 변경
- 이미지 보관함에서 사진을 다시 선택해 상품에 적용
- 관리자 메뉴에 '🖼 이미지 보관함' 추가
- 이미지/동영상 별도 보관
- 보관 파일 이름변경/삭제
- 상품별 '보관함에서 선택'
- 새 대표사진 업로드 후 보관함 저장 여부 선택
- 고객 화면 캐시 방지 즉시 반영

관리자 사용
ADMIN → 상품관리 → 상품수정
또는
ADMIN → 🖼 이미지 보관함
