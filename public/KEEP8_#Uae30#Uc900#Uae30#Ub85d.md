# 이룸 KEEP8 고정 기준

이 문서는 사용자가 좋다고 확정한 디자인과 기능을 다음 버전에서도 보존하기 위한 기준 기록입니다.

## 변경 금지 기준

- KEEP8의 밝은 크림·오프화이트 배경, 딥그린, 샴페인골드 색상
- 헤더와 메인이 자연스럽게 이어지는 구성
- 사용자가 만든 초록·샴페인골드 `이룸 / IROOM / PREMIUM FRUITS` 공식 로고
- 아치형 계절상품 카드와 한 카드당 한 상품 원칙
- 신고배는 실제 둥근 나주 신고배 이미지 사용
- 애플망고는 여름 계절상품으로 별도 노출
- 이미지 안에 메뉴·상품명·서비스 문구를 넣지 않고 HTML에서 한 번만 표시
- 화면의 뒤로가기는 한글 없이 화살표 아이콘만 표시

## 반드시 유지할 고객 기능

- 맞춤과일 추천
- 나만의 과일박스
- 주문조회와 주문 화면
- 검색
- 로그인·회원가입
- 마이페이지
- 장바구니
- 상품상세
- 계절 자동전환과 봄·여름·가을·겨울 선택
- FAQ·고객센터·BAND
- 앱 설치와 SEO 페이지

## 반드시 유지할 관리자 기능

- 홈페이지에서 관리자센터 진입 시 매번 비밀번호 확인
- 로그인 후 관리자 내부 이동에서만 인증 세션 재사용
- 대시보드
- 상품·과일·가격·재고·판매상태 관리
- 맞춤과일 상세 등록 폼
- 맞춤상담 요청 관리
- 주문·배송관리
- 회원관리
- FAQ·콘텐츠 관리
- SEO·사이트관리
- AI센터

## AI센터 고정 기능

- 상품 상세설명 작성
- 홍보·SNS 문구 작성
- 맞춤과일 상담 답변 초안
- SEO 제목·설명·키워드 작성
- 홈페이지 운영 점검
- 결과 복사와 초기화

## 버전 작업 원칙

1. 사용자가 `좋다`, `KEEP`, `기준으로 저장`이라고 확정한 내용은 이 문서에 추가합니다.
2. 새 버전은 이 문서의 기능을 삭제하지 않습니다.
3. 변경이 필요한 경우 기존 기준본을 복사한 새 버전에서만 작업합니다.
4. 연결되지 않은 가짜 버튼이나 장식용 관리 메뉴를 추가하지 않습니다.
5. 브라우저에서 로그인, 주요 버튼, 이미지, 중복 렌더링과 오류를 검사한 뒤 배포합니다.
