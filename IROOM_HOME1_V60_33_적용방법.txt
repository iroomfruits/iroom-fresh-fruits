IROOM HOME1 V60.33 HOME2 LUXURY GALLERY 적용방법

1. 현재 V60.32가 적용된 GitHub 저장소를 엽니다.
2. 이 ZIP을 압축 해제합니다.
3. ZIP 안의 package.json / public 폴더 / 문서 파일을 저장소 루트에 그대로 덮어씁니다.
4. 기존 저장소 전체를 삭제하지 마세요.
5. Render 자동 배포가 끝나면 /home2 를 확인합니다.
6. 캐시 때문에 이전 화면이면 Ctrl+Shift+R을 한 번 누릅니다.
