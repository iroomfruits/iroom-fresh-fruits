IROOM HOME1 V60.36 HOME2 EDITORIAL FRUIT HOUSE 적용방법

1. 현재 GitHub 저장소는 삭제하지 않습니다.
2. 이 ZIP을 압축 해제합니다.
3. package.json / public/ / 문서 파일을 GitHub 저장소 루트에 그대로 업로드합니다.
4. 같은 이름 파일만 덮어씁니다.
5. Render 재배포가 끝나면 /home2 를 확인합니다.
6. 이전 화면이 남으면 Ctrl+Shift+R 강력 새로고침을 합니다.

확인 포인트
- /home1은 기존 디자인과 계절 자동전환 그대로인지
- /home2는 계절 자동전환 없이 동일한 에디토리얼 디자인인지
- 사용자 제공 이룸 fresh fruits 로고가 상단/푸터에 적용되는지
- IROOM PICK 6종이 한 상품당 대표 이미지 1장으로 보이는지
- 상세보기에서 선택한 과일과 다른 과일 이미지가 섞이지 않는지
- BUY / 검색 / 로그인 / 장바구니 / 비회원 주문조회 / 카카오 상담이 정상인지
- 모바일에서 Hero → 상품 → Fruit Stories 순서가 자연스러운지
