IROOM HOME1 V60.15 적용 안내

- IROOM_HOME1_V60_15_GITHUB_PATCH.zip 압축을 풉니다.
- GitHub 저장소 루트에 그대로 덮어씁니다.

2) 이번 버전 DB 변경
- 서버 시작 시 orders 테이블에 아래 컬럼을 자동 추가합니다.
  privacy_agreed_at TIMESTAMPTZ
  terms_agreed_at TIMESTAMPTZ
- 별도 SQL 작업은 필요하지 않습니다.

3) 배포 후 반드시 실기기 확인
- 상품 담기 → 비회원 주문 → 주소 검색 → 필수 동의 → 주문 접수
- 주문완료 화면에서 주문번호 복사 / 계좌 복사 / 주문조회
- 푸터의 비회원 주문조회 → 주문번호 + 연락처로 조회
- 관리자에서 주문 상태/입금 상태 변경 → 비회원 주문조회에 반영 확인

4) 외부 주소검색
- 2026년 Kakao 우편번호 서비스 권장 도메인/네임스페이스를 사용합니다.
- t1.kakaocdn.net / kakao.Postcode
- 주소검색이 일시 실패해도 직접입력으로 주문 가능하게 유지했습니다.
