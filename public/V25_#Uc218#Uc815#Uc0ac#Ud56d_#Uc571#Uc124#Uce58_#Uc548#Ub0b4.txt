이룸 fresh fruits V25

1. 이미지 보관함
- ADMIN 왼쪽 메뉴에서 '🖼 이미지·동영상 보관함'을 골드색으로 강조
- 관리자 대시보드에도 큰 이미지 보관함 바로가기
- 상품관리 상단에도 이미지 보관함 버튼

2. 상품등록/수정
- '← 상품목록으로' 뒤로가기 버튼
- 신규 상품도 사진을 먼저 선택 가능
- 상품정보 + 사진 선택 후 '상품 등록 + 선택사진 바로 적용'
- 상품 생성 → 사진 업로드 → 대표사진 적용 → 같은 수정화면 유지
- 기존사진 삭제 / 새사진 바로 적용 / 보관함 선택 가능

3. 휴대폰 앱
- 홈페이지 상단 '📱 앱 설치'
- Android 설치 버튼
- iPhone 홈 화면 설치 버튼
- PWA manifest / service worker / 앱 아이콘 유지

휴대폰에서 실제 설치하려면 홈페이지가 HTTPS 주소로 공개되어 있어야 합니다.

Android는 Chrome에서 PWA 앱 설치가 가능합니다.
iPhone은 Safari → 공유 → 홈 화면에 추가 방식입니다.

Google Play용 APK/AAB 및 App Store용 iOS 앱은 별도의 앱 서명/스토어 등록이 필요합니다.
