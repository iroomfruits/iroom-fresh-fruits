IROOM HOME2 수입코너 쉬운 패치

적용 내용
1) 메인에 "해외 과일 셀렉트" 섹션 추가
2) 과일 셀렉트(전체 상품) 페이지에 "해외 셀렉트" 탭 추가
3) 프리미엄 페인터리 스타일 수입 과일 이미지 4종 추가
   - 체리(기존 spring 체리 카드도 새 이미지로 교체)
   - 오렌지
   - 망고
   - 자몽
4) 서비스워커 캐시 버전 갱신

- ZIP 압축을 풀고, 안의 public 폴더를 기존 프로젝트 루트에 그대로 덮어쓰기
- 업로드 후 재배포
- 브라우저 새로고침이 꼬이면 Ctrl+F5 또는 시크릿창 확인
