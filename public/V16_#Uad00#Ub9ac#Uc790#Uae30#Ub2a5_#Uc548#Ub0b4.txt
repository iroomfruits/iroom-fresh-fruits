관리자에서 가능한 기능
- 상품 등록/수정/삭제
- 상품 대표이미지 직접 업로드
- 상품 동영상 직접 업로드
- 가격/할인가/산지/구성/재고/판매상태
- 상품별 배송비/무료배송기준/최대구매수량
- 저재고 자동 표시
- 주문/결제상태 관리
- 배송상태 관리
- 국내 주요 택배사 선택 + 송장번호 + 배송조회 링크
- 주문 메모
- 취소요청/환불요청 확인
- 취소완료/환불완료 시 재고 자동 복구
- 환불금액/사유/방법 기록
- 회원관리
- 이벤트/쿠폰/배너/팝업 관리
- 리뷰/문의 관리
- 주문 CSV 내보내기
- 사업자정보/계좌/배송비/무료배송 기준
- PG/네이버페이/카카오페이 키 입력란
- 네이버 SMTP/SENS 문자 키 입력란
- 개인정보처리방침/환불정책
- 관리자 작업 로그

실제 자동 결제/자동 문자/택배 API 실시간 상태조회는 각 서비스 사업자 계약과 API 키가 필요합니다.
키가 없는 경우에도 주문/송장/환불/상품/재고 관리 자체는 정상 사용할 수 있습니다.
