IROOM HOME1 V60.10 — 간편 앱 설치 UX

1. 홈페이지 앱 설치 영역을 약 920px 이하의 컴팩트 가로 배너로 축소했습니다.
2. 배너에는 이룸 fresh fruits 로고와 “이룸 앱 설치” 버튼만 표시합니다.
3. Chrome / Edge / Android: 브라우저 설치 프롬프트가 준비되면 한 번의 클릭으로 시스템 설치창을 엽니다.
4. Edge/Chrome에서 자동 설치창이 준비되지 않은 경우 실패 문구 대신 주소창의 앱 설치 아이콘 위치만 짧게 안내합니다.
5. iPhone/iPad Safari: 공유(□↑) → 홈 화면에 추가 → 추가의 최소 단계만 안내합니다.
6. 카카오/네이버/인스타 등 인앱 브라우저는 Chrome/Safari로 전환하도록 안내합니다.
7. 실제 PWA로 실행 중인 경우 설치 배너는 숨깁니다.
8. 설치 아이콘은 사용자가 선택한 이룸 fresh fruits 로고(V60.9 아이콘 디자인)를 그대로 유지하면서 캐시 갱신을 위해 V60.10 이름으로 연결했습니다.

브라우저 보안 정책상 웹페이지가 사용자의 동의 없이 앱 설치나 바탕화면 바로가기를 자동 생성할 수는 없습니다. 설치 프롬프트가 제공되는 환경에서는 가능한 한 한 번의 버튼 클릭으로 설치를 시작합니다.
